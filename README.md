## 🌟 Características de diseño y funcionalidad

1. **Diseño de una sola pantalla (Single Screen)**:
   - Centrado, limpio y optimizado con prioridad absoluta para dispositivos móviles (`mobile-first`).
   - Paleta de color premium: azul marino pizarra (`#080D17` / `#101827`), reflejos esmerilados de cristal líquido, acentos en oro cálido champán (`#E5B869`) y verde confianza esmeralda (`#10B981`).

2. **Acciones rápidas de contacto**:
   - Botón grande de **WhatsApp**: Abre chat directo con texto predefinido listo para enviar.
   - Botón grande de **Llamar**: Conexión telefónica directa al pulsar.
   - Botón grande de **Email**: Abre el gestor de correo con asunto preparado.

3. **Guardar Contacto en 1 Clic (vCard 3.0)**:
   - Botón dorado destacado con animación de brillo.
   - Genera y descarga al instante el archivo `Maria_Ortiz_Uriarte.vcf` con soporte optimizado tanto para **iOS** (importación directa a la app Contactos) como para **Android** y escritorio.

4. **Visor de Código QR integrado**:
   - Modal emergente que genera el código QR dinámico de la tarjeta para que cualquier persona o cliente presencial pueda escanearla en segundos con la cámara de su teléfono móvil.
   - Botón para copiar el enlace directo al portapapeles con aviso visual flotante (toast feedback).

5. **Compartir mediante API nativa**:
   - Botón "Compartir" con integración de la Web Share API nativa de teléfonos inteligentes.

6. **Archivo único autónomo**:
   - Todo el HTML, CSS y JavaScript están integrados dentro de [index.html](file:///Users/itxasportatil/tarjetapresentacionmariaortiz/index.html), sin dependencias complejas y listo para publicar directamente en GitHub Pages, Netlify o cualquier servidor.
